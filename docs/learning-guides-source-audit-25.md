| 卦辞 | 以刚自外来、动而健与刚中相应解“无妄”，不正而往则有眚；带上古君臣、礼法秩序的解释。 | 朱熹释“无妄”为实理自然，兼录《史记》作“无望”的解释，重正固而不妄动。 | **有异文和训释分支**。不能把一切意外都归为当事人道德有过。 |
| 初九 | 王注以刚居下、行不妄、教化有正释“往吉”。 | 《本义》以初九刚居内、诚为主解其可以往。 | 往吉有其卦爻条件，不是鼓励不审实际风险的冲动。 |
| 六二 | 王注与孔疏从臣不擅事始、守成而不专美说“不耕获，不菑畬”，含鲜明臣道立场。 | 朱熹强调顺时无私，无所期望前利后获；并非不劳获利。 | 两者重点分别在**不擅君功**与**无私意期望**，不能统称“免劳而有收获”。 |
| 六三 | 王注孔疏将行人解释为有司，解释邑人越分耕作、有司制之而得牛，使邑人受罚；含强烈古代政治归责。 | 朱熹明确以六三不当位、无故逢灾举例：行人牵牛走，居者反被盘查牵连。 | **重要分歧**：王注孔疏的“越分受罚”和朱熹的“无故牵累”不得混作同一古义；也不能从前说推出现代受害者必有过错。 |
| 九四 | 《正义》以阳处阴、近尊而守正解“可贞，无咎”。 | 《本义》重乾刚而下无应，固守而无咎，偏向不有所为。 | 固守条件明确，不等于所有工作必须停止。 |
| 九五 | 《正义》王注讲九五本无妄、忽遇无妄之疾，若妄施药反致害；孔疏先描述古代对“自然之疾”的治法，继而**明言假病象以喻人事**，举君主遭灾的政事比拟。 | 朱熹以中正无妄而遭疾、勿药则自愈说占辞，又在《象》下注称妄药可能反生疾。 | **高风险边界**：“勿药”是古占辞与传统医疗观，**绝不构成现实停药、拒诊、停治建议**；不得以古文取代现代循证医疗。 |
| 上九 | 王注孔疏说处无妄之极、继续向前反有眚，唯宜静保。 | 朱熹也重并非有妄，而是穷极不可行。 | 反驳“无妄即无论何时皆宜往”的机械解释。 |
