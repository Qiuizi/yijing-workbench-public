# 《周易》学习导读逐条复核记录（V1 全覆盖 PR）

> 本文记录**实际核验过**的卦和问题。内容已写满 64 卦，不代表 64 卦全部审定。所有尚未完成逐条文献对照的卦仍保持 `draft`，不得批量切换为 `reviewed`。

## 核验方法

1. 对照 `backend/data/hexagrams.json` 的原文，维持现有经文的字形和标点，不因注家句读与项目标点不同而悄悄改动经典数据。
2. 对照维基文库电子转录的《周易正义》对应卦爻；每一处归属须写明究竟来自经文、王弼注、孔颖达疏，还是现代编辑。
3. 有实质分歧时并列，不得把现代伦理或一般性建议冒充经文和古注；古注中的古代刑罚、君臣、婚配、疾病制度照实说明但不视为今日行为命令。
4. 核验后修改 JSON 同时同步对应审核文档，改动前后应可追溯。**通过校对不等于用户已确认正式发布**。
