## 可逐条定位、已复核的重点依据（仅以下事项）

1. **13 同人九四句读**：[《周易正义》“弗克攻，吉”](https://zh.wikisource.org/wiki/周易正義/02同人)，所核读段落把不攻而反归法则视作吉；项目的经文标点不得偷改。当前导读已提醒句读差异，暂不改。
2. **17 随上六“王用亨于西山”**：[《周易正义》“王用亨于西山”](https://zh.wikisource.org/wiki/周易正義/02隨) 明将“亨”释为用兵通险，朱熹《本义》另从“享”理解为祭祀。项目稿已分别归属，暂不改。
3. **23 剥卦辞**：[《正义》卷三](https://zh.wikisource.org/wiki/周易正義/03剝) 录“不利有攸往”，与项目经典 `剝：不利。有攸往。` 标点不同。现代概述已有“不利前往”，本次不擅改经典转录。
4. **25 无妄六三**：[《正义》卷三](https://zh.wikisource.org/wiki/周易正義/03無妄) 疏把“行人”指有司、并据古代政治名分解释得牛、受灾，当前现代稿提示不能用此断定现实受害者必有错。
5. **28 大过九二**：参 [《正义》卷三](https://zh.wikisource.org/wiki/周易正義/03大過) 及 [《周易傅义》朱熹《本义》段落](https://www.shidianguji.com/book/HY1972/chapter/1koi4a7zei13e)。`稊` 所指有再生之秀与根部两类训释；《本义》见“稊，根也”，部分电子录文“梯”不宜直接当成朱熹原稿。**本轮已订正 JSON 和对应审稿文档**。
6. **63 既济六四**：[《正义》卷六](https://zh.wikisource.org/wiki/周易正義/06既濟) 明言王注“繻宜曰濡”，`衣袽` 为塞舟漏之物。现代稿已记录异文，不改经典字段。
