# v3.3.2 发布说明（草稿）

> 状态：**未发布**。本文件只作为 `release.yml` 的 `notes_file` 输入；正式发布前需随版本内容最后校对。

## 新增：应用内自动更新

- 启动后最多每 24 小时检查一次更新；也可在「设置 → 关于应用 → 应用更新」手动检查。
- 发现新版本时显示版本号、发布日期与更新说明，**由用户确认后**才下载并安装。
- 下载过程显示真实进度、速度与剩余时间；失败可重试。
- 更新包经 Tauri updater 数字签名校验，签名不符或包被篡改会拒绝安装。
- 支持关闭自动检查；关闭后仍可手动检查。

## 数据安全

- 安装前自动创建 SQLite 一致性备份（在线备份 API，兼容 WAL），备份失败即取消安装。
- 安装前停止本地 Python 服务，安装后自动重启为新版本。
- 历史记录、偏好设置与 DPAPI 保护的 API Key 原地保留，不上传任何数据。

## 兼容性与升级路径

- **v3.3.1 及更早版本没有更新器**，升级到 v3.3.2 需要手动安装一次。
- 从 v3.3.2 起，后续版本可自动升级。
- 安装模式仍为 currentUser（无需管理员），应用标识 `cn.yijing.workbench` 不变。

## 隐私说明

应用有两类联网行为：主动调用 AI 时的 DeepSeek 请求，以及更新检查时的 GitHub 请求。更新检查只发送版本信息，不包含卦象、历史、设置或 API Key。详见 `PRIVACY.md`。

## 已知限制

- 安装包未做 Windows Authenticode 代码签名，首次运行仍可能出现 SmartScreen 提示。
- 未实现自动回滚；安装失败时旧版本与数据库均保留，可按 `docs/updater/README.md` §9 人工恢复。
