### 05 水天需

来源：[《周易正义》卷二·需](https://zh.wikisource.org/wiki/周易正義/02需)。

| 位置 | 《正义》电子文本对应解释 | 本轮判定 |
| --- | --- | --- |
| 卦辞 | 疏释「需」为待，「险在前」是所以须待之故，同时又承认刚健得中可以涉险前进，不能把整卦读成永远勿行。 | 对照既有导读，暂不改 |
| 初九 | 注疏说明郊在险难之外，宜守常以远害，所论仍是具体处境里的等待。 | 对照既有爻注，暂不改 |
| 九二 | 沙临水而尚未逼近深险，「小有言」释作责让之言，居中待会因而终吉。 | 对照既有爻注，暂不改 |
| 九三 | 逼近险难、自招寇至；王注及疏都给「敬慎防备，可以不败」的限定。 | 对照既有爻注，暂不改 |
| 六四 | 王注将血归于阴阳相伤、穴归于阴之路；疏又说明血与穴是不同象境，不可直接推出受伤者应现实退让。 | 对照既有爻注，暂不改 |
| 九五 | 居中得正、已居天位，酒食宴乐为待时的象征，而非喝酒带来好运的法术。 | 对照既有爻注，暂不改 |
| 上六 | 疏明确释「速」为召，三人指初九、九二、九三；既有稿不得把三人转成现实人数预言。 | 对照既有爻注，暂不改 |

### 06 天水讼

来源：[《周易正义》卷二·讼](https://zh.wikisource.org/wiki/周易正義/02訟)。

| 位置 | 《正义》电子文本对应解释 | 本轮判定 |
| --- | --- | --- |
| 卦辞 | 疏释「窒」为塞、「惕」为惧，「中吉」明确关联中道止讼，终竟争讼为凶。 | 对照既有导读，暂不改 |
| 初六 | 注疏区分见犯而讼与自己挑起争讼；止争不等于不能辨明是非。 | 对照既有爻注，暂不改 |
| 九二 | 王注和孔疏以自下讼上为不克，归逋小邑避害；对「其邑／人三百户」句读另有解释，不可定为现实人数指标。 | 对照既有爻注，暂不改 |
| 六三 | 「食旧德」指保有旧日德禄位；王注孔疏以从上、不争理解「或从王事无成」。 | 对照既有爻注，暂不改 |
| 九四 | 「复即命渝」疏明确作返回原先不争之理、改变前命，不是默认胜者永远有理。 | 对照既有爻注，暂不改 |
| 九五 | 注疏认为九五是居尊中正的断讼者，不同于卦辞告诫当事人讼不可终；还讨论九二与九五作为不同意义的「主」。 | 对照既有爻注，暂不改 |
| 上九 | 鞶带为命服大带，因讼得赏不足以长保；疏把终朝三褫连于不能久享荣誉。 | 对照既有爻注，暂不改 |

### 07 地水师

来源：[《周易正义》卷二·师](https://zh.wikisource.org/wiki/周易正義/02師)。

| 位置 | 《正义》电子文本对应解释 | 本轮判定 |
| --- | --- | --- |
| 卦辞 | 疏训师为众、贞为正，王注将丈人解作严庄之称；其军事伦理与古代统属相关。 | 对照既有导读，暂不改 |
| 初六 | 王注与孔疏将「否／臧」分别联系败与功，强调失律即使有功仍可为凶；不得改成唯战果论。 | 对照既有爻注，暂不改 |
| 九二 | 孔疏明确讨论「在师中／吉」的王注句读与《象》「在师中吉」有不同重心；三锡命是古代奖命制度。 | 已定位分歧，暂保留原注 |
| 六三 | 王注以阴居阳、进退无据说明「舆尸」凶，保留真实伤亡意象而不将它虚化。 | 对照既有爻注，暂不改 |
| 六四 | 注疏以六四得位无应说明可止不可行，并援古代兵法解释左次的营驻方位；不必一律读作战败。 | 对照既有爻注，暂不改 |
| 六五 | 王注孔疏把田中禽害苗稼比作来犯而后出师，「利执言」以受侵为前提；长子、弟子联系九二、六三受任得失。 | **修订**原稿泛称「田猎有禽」的模糊释义 |
| 上六 | 疏以功大小分为诸侯开国与卿大夫承家，「小人勿用」是旧制封赏与用人之论。 | 对照既有爻注，暂不改 |

### 08 水地比

来源：[《周易正义》卷二·比](https://zh.wikisource.org/wiki/周易正義/02比)。

| 位置 | 《正义》电子文本对应解释 | 本轮判定 |

| 初六 | 注疏把诚信盈缶作为信实使众人来比的象，不是字面保证现实生活有贵人。 | 对照既有爻注，暂不改 |

| 上六 | 王注孔疏联系迟来不能为亲比之首，故被弃而无终；不得与乾用九的「无首」混为一谈。 | 对照既有爻注，暂不改 |
