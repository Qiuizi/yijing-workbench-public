# 六十四卦原文数据

## 来源与版本

`hexagrams.json` 的卦名、文王序、卦象、卦辞和六条爻辞依据维基文库《周易》各卦页面“易经”部分整理；未把《彖》《象》《文言》等《易传》混入经文。字形、异体字和标点沿用所指页面；不同传本可能有异文。

每条卦记录的 `source_revision_id` 保存 MediaWiki 修订号，`source_url` 使用对应 `oldid` 永久链接。核对日期：**2026-09-24**。该日通过维基文库 MediaWiki API 查询 64 个页面的修订号，并将本地 64 条卦辞、384 条普通爻辞及乾坤特殊爻辞与对应修订内容逐条核对；共核对 450 项文本，均匹配。乾、坤所据修订分别为 [乾 2404991](https://zh.wikisource.org/w/index.php?title=%E5%91%A8%E6%98%93%2F%E4%B9%BE&oldid=2404991)、[坤 2404999](https://zh.wikisource.org/w/index.php?title=%E5%91%A8%E6%98%93%2F%E5%9D%A4&oldid=2404999)。修订号标识网页内容版本，不等同于古籍底本或校勘本名称。

维基文库页面文本按页面所示 CC BY-SA 4.0 提供。来源总目：[维基文库《周易》](https://zh.wikisource.org/wiki/周易)。逐卦页面和修订号见 `hexagrams.json` 各条记录；来源链接固定到已核对的页面修订。

## 收录范围与校验

收录 64 卦、每卦卦辞和按初爻至上爻排列的六条普通爻辞；另以独立 `special_line` 字段收录乾卦“用九：見羣龍无首，吉。”和坤卦“用六：利永貞。”，不扩展六爻数组，也不把特殊爻辞作为第七爻。其它卦记录不设该字段。

当前不收录《易传》各篇、注疏、现代解释及异文校勘资料；来源页面对应的纸本底本未在本项目中另行确认。修订号与核对日期可复现本次取用的网页文本，但不能消除版本差异。

目录加载时检查 64 个修订号和固定来源链接、特殊爻辞仅出现在第 1/2 卦，以及特殊标签、原文前缀和来源链接的一致性。卦序与卦象编码的验证还检查 1–64 文王序、编码唯一性、上下卦关系；算法测试穷举 64 种阴阳组合及 4096 种六爻值组合。
